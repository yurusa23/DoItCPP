# 1. 데이터의 집과 주소 (변수, 포인터, 레퍼런스)
> 컴퓨터의 메모리는 수많은 방이 있는 아파트와 같습니다. 프로그램이 실행되면 각 데이터는 고유한 방(주소)을 배정받습니다.

* **변수 (일반 거주자)**: 메모리 공간에 크기에 맞게 방을 확보하고 들어가는 데이터입니다. 
  * _예)_ `char`는 1바이트 크기의 방, `int`는 4바이트, `double`은 8바이트 크기를 차지합니다.

* **주소 연산자 `&` (방 번호 확인)**: 변수 이름 앞에 `&`를 붙이면, 해당 데이터가 살고 있는 아파트의 **'시작 방 번호(메모리 주소)'**를 알려줍니다.

* **포인터 변수 `*` (주소록)**: 데이터가 직접 들어가는 것이 아니라, 다른 변수의 **'방 번호(메모리 주소)'**만을 적어두는 특수한 변수입니다. 
  * 어떤 데이터를 가리키든 주소만 적으면 되기 때문에, 포인터 변수의 크기는 데이터 형식과 무관하게 항상 동일합니다.

* **역참조 연산자 `*` (리모컨)**: 포인터 변수 앞에 `*`를 붙이면, 단순히 주소록을 읽는 것을 넘어 그 주소로 직접 찾아가 데이터를 읽거나 덮어씌웁니다. TV 리모컨으로 원격 조종을 하는 것과 같은 원리입니다.

* **레퍼런스 `&` (별명)**: 포인터처럼 복잡하게 주소를 다루는 대신, 이미 존재하는 변수에 **'새로운 별명'**을 하나 더 붙여주는 기능입니다. 
  * 선언 직후 반드시 원본 변수를 지정해야 하며, 한 번 지정된 대상은 다른 변수로 바꿀 수 없습니다.

# 2. 메모리 동네의 종류 (스택 vs 힙 vs 데이터 영역)
> 데이터의 성격에 따라 배정받는 아파트 단지(메모리 영역)가 다릅니다.

* **스택 (Stack) 영역 — "자동 임대 주택"**
  * **거주자**: 일반적인 지역 변수들
  * **특징**: 함수 블록 `{ }` 안에서 선언되며, 함수가 종료되면 시스템(OS)이 자동으로 방을 빼버립니다(소멸).
  * **주의**: 할당 가능한 공간이 적어 한도를 초과하면 프로그램이 강제 종료(**스택 오버플로**)됩니다.

* **힙 (Heap) 영역 — "자가 소유 주택 (동적 메모리)"**
  * **거주자**: 동적으로 생성된 메모리 데이터
  * **특징**: 개발자가 직접 크기를 정해서 땅을 사고(`new`), 직접 팔아야 하는(`delete`) 공간입니다. 함수가 종료되어도 데이터가 사라지지 않고 유지됩니다.
  * **주의**: 만약 다 쓰고 나서 `delete`로 반환하지 않으면, 아무도 안 쓰는데 자리만 차지하는 **'메모리 누수'**가 발생합니다.

* **데이터 영역 — "영구 거주지"**
  * **거주자**: 전역 변수나 `static`(정적) 키워드가 붙은 변수들
  * **특징**: 프로그램이 시작될 때 한 번만 생성되고, 프로그램이 완전히 종료될 때까지 값이 누적되며 유지됩니다.

# 3. 데이터의 묶음과 접근 (배열과 구조체)
> 여러 데이터를 효율적으로 관리하기 위해 묶어 쓰는 방식입니다.

* **배열 (연립 주택)**
  * 완전히 똑같은 자료형의 변수 여러 개를 일렬로 묶은 것입니다.
  * 인덱스는 0부터 시작하며, **배열의 이름 자체가 '첫 번째 방의 시작 주소'**를 의미합니다.

* **구조체 (복합 상가)**
  * 서로 다른 자료형의 변수들을 하나로 묶어 새로운 형태를 만드는 것입니다.
  * 내부의 개별 데이터에 접근할 때:
    * 일반 변수 형태면 **점(`.`)**을 사용
    * 동적 메모리로 선언된 포인터 형태면 **화살표(`->`)**를 사용
