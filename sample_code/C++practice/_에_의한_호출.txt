# 1. 값에 의한 호출 (Call by Value) : "엑셀 파일 복사본 보내기"
- **상황**: 내 컴퓨터에 있는 '매출 장부.xlsx' 파일을 USB에 복사해서 외주 직원에게 줍니다.

- **작동 원리**: 직원이 자기 컴퓨터에서 그 파일을 열고 내용을 다 지우든, 숫자를 100배로 튀기든 내 컴퓨터에 있는 원본 파일은 아무런 영향을 받지 않습니다. 매개변수로 전달된 일반 변수는 함수 내 지역변수이기 때문에 함수 외부에서는 변동이 없습니다.

- **장단점**: 원본이 절대적으로 안전하지만, 데이터가 엄청나게 클 경우 복사하는 데 시간과 메모리가 낭비됩니다.

- **사용 형태**: 
  ```cpp
  void func(int a) // ➔ 호출 시 func(x)
  ```

# 2. 주소에 의한 호출 (Call by Address) : "구글 스프레드시트 링크 보내기"
- **상황**: 파일을 복사해 주는 대신, 내 파일이 있는 '서버의 주소(URL)'와 수정 권한을 카톡으로 보내줍니다.

- **작동 원리**: 직원이 그 링크(포인터)를 타고 직접 내 문서로 들어와서 숫자를 수정합니다. 직원이 작업을 마치고 나가면, 내 문서의 원본 데이터도 직원이 수정한 대로 바뀌어 있습니다.

- **장단점**: 복사할 필요 없이 가볍게 주소만 넘기면 되고 원본 수정이 가능합니다. 하지만 함수를 호출할 때마다 주소 기호(&)를 붙여야 하고, 함수 안에서도 매번 역참조 기호(*)를 써야 해서 코드가 매우 지저분해지고 실수하기 쉽습니다.

- **사용 형태**: 
  ```cpp
  void func(int* a) // ➔ 호출 시 func(&x)
  ```

---

# 3. 참조에 의한 호출 (Call by Reference) : "같은 사람에게 별명 부르기"
- **상황**: C++에서 새롭게 만든 혁명적인 문법입니다. 복잡한 주소나 링크를 넘기는 대신, 아예 내 문서 자체에 '새로운 이름표(별명)'를 하나 더 붙여줍니다.

- **작동 원리**: 예를 들어 내 원래 변수 이름이 a인데, 함수에게 "이제부터 너는 얘를 b라고 불러, 근데 사실 둘은 완벽하게 똑같은 놈이야"라고 연결해 줍니다. 직원이 b를 수정하면 그게 곧 a를 수정하는 것과 완벽히 같습니다.

- **장단점**: 주소 연산자(&)나 포인터(*) 같은 복잡한 기호를 덕지덕지 붙일 필요 없이, 일반 변수처럼 아주 깔끔하게 코드를 쓰면서도 원본을 직접 수정할 수 있습니다.

- **사용 형태**: 
  ```cpp
  void func(int& a) // ➔ 호출 시 func(x) (일반 호출과 모양이 똑같아서 아주 편함!)
  ```
