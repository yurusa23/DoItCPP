1. 포인터와 동적할당
	포인터(*,&)-데이터 자체가 아니라, 데이터가 있는 '금고의 주소(메모리 주소)'를 저장하는 변수
	동적 할당(new, delete)-프로그램 실행 중에 필요한 만큼 메모리를 할당받아 사용하는 방법
		- new: 메모리를 할당받아 주소를 반환
		- delete: 더 이상 필요 없는 메모리를 반환하여 재사용 가능하게 함

2. 구조체와 구조체 배열
	구조체(struct)-서로 다른 자료형의 변수들을 하나로 묶어 새로운 데이터 타입을 만드는 방법
	데이터 접근방법-
		- 일반 변수 형태: 점(.) 연산자 사용
		- 동적 메모리로 선언된 포인터 형태: 화살표(->) 연산자 사용

3. 함수로 데이터 넘겨주기 (호출의 3가지 방법)
 	값에 의한 호출-함수에 인자로 전달된 데이터의 복사본이 함수 내부로 전달됨. 원본은 두고 복사본이 함수 내부에서 사용됨. 함수가 원본을 수정 할 수 없음
	참조에 의한 호출-함수에 인자로 전달된 데이터의 주소가 함수 내부로 전달됨. 변수에 별명&를 붙여 원본을 직접 수정 가능. 단 , 참조는 한 번 설정된 대상은 변경할 수 없음
	포인터에 의한 호출-함수에 인자로 전달된 포인터가 함수 내부로 전달됨, 포인터를 통해 원본 데이터에 접근 가능. 금고 위치(포인터)를 던져 역참조*로 원본을 고칠 수 있음.
