# 1. 데이터의 형태 구별: 배열(Array) vs 포인터(Pointer)
이 둘은 변수를 '처음 만들 때(선언할 때)' 변수 이름 주변에 붙어있는 기호를 보고 구별합니다.

### 📦 배열 (Array): 대괄호 [ ]를 찾아라!
- **시각적 특징**: 변수를 만들 때 이름 뒤에 대괄호 `[크기]`가 붙어 있습니다.
- **의미**: "나는 똑같은 크기의 방 여러 개를 하나로 묶어 길게 만들어낸 거대한 건물이다!"라는 뜻입니다. 인덱스로 개별 변수에 값을 읽거나 씁니다.
- **코드 예시**: 
  ```cpp
  int my_array[5]; // 정수 방 5개짜리 배열 생성
  ```

### 🎯 포인터 (Pointer): 별표 *를 찾아라!
- **시각적 특징**: 변수를 만들 때 자료형(int, double 등) 바로 뒤에 별표 `*`가 붙어 있습니다.
- **의미**: "나는 실제 건물이 아니라, 다른 건물의 시작 메모리 주소를 저장하는 얇은 메모지(변수)다!"라는 뜻입니다. 포인터가 저장하는 데이터는 메모리 주소입니다.
- **코드 예시**: 
  ```cpp
  int* my_pointer; // 주소를 담을 수 있는 포인터 생성
  ```

# 2. 함수에서의 역할 구별: 매개변수(Parameter) vs 전달인자(Argument)
이 둘은 함수와 관련된 괄호 ( ) 안에 들어있다는 공통점이 있습니다. 하지만 '위치'와 '자료형의 유무'로 완벽하게 구별할 수 있습니다.

### 📝 매개변수 (Parameter): 함수의 '설계도(도면)'를 찾아라!
- **시각적 특징**: 함수를 처음 정의할 때 괄호 안에 적혀 있습니다. 반드시 앞에 int, double, char* 같은 '자료형'이 함께 명시되어 있습니다.
- **의미**: "우리 공장(함수)이 돌아가려면 이런 형태의 재료(투입구)가 필요해!"라고 규격을 정해놓은 것입니다.
- **코드 예시**: 
  ```cpp
  void do_something(int x, int* y);
  ```
  > 여기서 `int x`와 `int* y`가 매개변수입니다. (자료형이 붙어있음)

### 🚀 전달인자 (Argument): main 함수 안의 '실제 호출(현장)'을 찾아라!
- **시각적 특징**: 이미 만들어진 함수를 실제로 사용할 때(호출할 때) 괄호 안에 적혀 있습니다. 여기에는 절대 자료형이 붙지 않고, 오직 변수의 이름이나 실제 숫자, 주소 기호(&)만 들어갑니다.
- **의미**: "공장 투입구 규격에 맞춰서, 내가 가진 진짜 재료(동전)를 밀어 넣을게!"라는 뜻입니다.
- **코드 예시**: 
  ```cpp
  do_something(a, &b);
  ```
  > 여기서 `a`와 `&b`가 전달인자입니다. (자료형 없이 진짜 값만 던짐)
